# Data Directory

This folder contains the WCAG source data and generated normalised advisor data used by `accessibility-advisor-mcp`.

## Source data

- `wcag.json` — pinned WCAG 2.2 source dataset used by the advisor service.
- `wcag/` — W3C WCAG git submodule, retained as the upstream source for Understanding documentation parsing.

## Normalised data

`data/normalised/` is generated by the advisor build pipeline:

- `criteria.json`
- `techniques.json`
- `glossary.json`
- `topic-index.json`
- `component-rules.json`

## Updating and validating data

```sh
npm run build
npm run normalise
npm run validate:data
```

The build script attempts to update the W3C submodule, fetch the published WCAG JSON, parse Understanding documents, normalise advisor data, and validate the resulting dataset. If external network access is unavailable but a pinned `data/wcag.json` exists, the build can still normalise and validate local data.
