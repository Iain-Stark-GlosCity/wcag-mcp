# Attribution

This project is MIT licensed software that includes and derives accessibility reference data from W3C Web Content Accessibility Guidelines (WCAG) 2.2 and Understanding WCAG 2.2 material.

WCAG source material is copyright W3C and used under the W3C Document Licence. Tool responses include source links to the WCAG specification, Understanding pages, and the WAI Quick Reference where a criterion is used.

Local advisor rules are implementation guidance for council/public-sector website generation. They are not normative WCAG text and must remain distinguishable from W3C source material.
